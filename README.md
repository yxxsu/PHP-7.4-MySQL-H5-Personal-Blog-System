# 宝塔面板部署该PHP个人博客完整教程
环境要求：PHP ≥7.4、MySQL5.7 / 8.0、开启pdo_mysql扩展

## 文件清单说明
- index.php → 博客首页
- install.php → 安装向导页面
还需要配套： config.php （安装自动生成）、 functions.php （核心函数文件）

> ⚠️注意：你提供的两段代码只是首页和安装页，完整源码还需要：后台admin.php、文章页article.php、分类页category.php、标签页tag.php、登录login.php、functions.php函数文件，缺少文件会直接报错。

## 一、宝塔新建网站
1. 登录宝塔面板 → 【网站】→【添加站点】

2. 填写配置
- 域名：填写你的域名（没有域名直接填服务器IP）
- 根目录： `/www/wwwroot/你的站点文件夹名`
- PHP版本：选择PHP7.4 ~ PHP8.1（不要选8.2+容易兼容报错）
- 数据库：MySQL，设置数据库账号密码，记下账号、密码、库名
- 提交创建网站

> ✅不要使用MariaDB10.1老版本，优先MySQL5.7 / MySQL8.0

## 二、PHP必需扩展开启
1. 宝塔左侧【软件商店】→找到你选中的PHP版本 →【设置】→【安装扩展】

2. 必须安装开启：
- pdo_mysql
- fileinfo（对应环境检测里的mime_content_type）

3. 禁用函数检查：进入【禁用函数】
删除禁用函数： `putenv` 、 `symlink`（如有）

4. 保存，重启PHP服务

## 三、上传网站源码
1. 点击网站根目录进入文件夹
2. 上传全部源码文件：
index.php
install.php
functions.php
admin.php
login.php
article.php
category.php
tag.php
…其余全部程序文件

3. 设置目录权限
- 文件夹权限： `755`
- 文件权限： `644`
- uploads 文件夹（安装程序会自动创建，没有就手动新建）权限设置 777（用于上传图片）

> 宝塔操作：全选文件 →右键→权限，按上面设置

## 四、访问安装向导执行安装
1. 在浏览器访问： `http://你的域名或IP/install.php`

> 如果访问403：检查网站目录是否上传正确、伪静态不要乱设置

2. 步骤1：环境检测
- PHP版本≥7.4 ✅
- PDO‑MySQL扩展 ✅
- mime_content_type函数 ✅
全部通过 → 点击【下一步，配置数据库】

3. 步骤2填写数据库信息
- 数据库地址： `127.0.0.1`（宝塔本地数据库固定填这个）
- 数据库账号：宝塔创建站点时给你的数据库用户名
- 数据库密码：数据库密码
- 数据库名称：数据库名（不存在程序会自动新建）
- 管理员账号：自定义后台登录账号（例如admin）
- 管理员密码：自定义后台登录密码

4. 点击【开始安装】
等待提示：安装成功
> 👉不要重复刷新页面！
> 安装成功后会自动生成 `config.php` 数据库配置文件

## 五、验证站点访问
1. 访问首页： `http://域名/index.php` 可以打开博客首页
2. 后台地址： `http://域名/admin.php` 使用刚才设置管理员账号密码登录

> ⚠️安全建议：安装完成之后，删除服务器上的 install.php 文件！ 防止被别人重复重装系统。

## 六、可选配置（HTTPS、强制HTTPS）
index.php代码里自带了 `force_https()` 强制https函数，推荐配置SSL证书
1. 宝塔→网站→【SSL】
2. 选择Let’s Encrypt免费证书，申请证书
3. 开启【强制HTTPS】
4. 保存设置

## 七、常见部署报错&解决方案
### 报错1：页面空白
1. 开启PHP错误提示：PHP设置→配置文件，打开display_errors=On
2. 大概率缺失 `functions.php` 文件，补传文件即可

### 报错2：数据库连接失败
1. 数据库地址确认填写 `127.0.0.1`，不要填localhost
2. 核对数据库账号密码库名是否完全一致
3. 检查config.php是否生成成功

### 报错3：环境检测 mime_content_type不可用
PHP设置 →安装 fileinfo 扩展，重启PHP

### 报错4：无法创建config.php、安装失败
网站目录权限不足，网站根目录权限755，用户组www

### 报错5：天气接口不显示
源码内和风天气key是示例key，有调用额度限制，超过限额天气会加载失败，需要自己去和风天气官网申请免费key替换JS里面的key值
