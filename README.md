# PHP-7.4-MySQL-H5-Personal-Blog-System
薄荷绿UI个人博客系统简介   这是一款基于PHP7.4+MySQL开发、自带一键安装程序的轻量化个人博客系统，采用清新薄荷绿渐变UI，搭配毛玻璃、悬浮动效、立体阴影，界面精致美观。   系统自带完整安装流程，自动检测运行环境、创建数据库与数据表，一键生成配置文件。功能涵盖文章发布展示、分类标签管理、侧边栏博主信息、站点公告、日历、实时天气、团队招募、社交链接、ICP备案展示等。   内置完善后台登录体系，支持站点名称、LOGO自定义配置，前台布局自适应，搭配流畅动画效果，无需复杂配置，安装即用，适合个人搭建专属博客站点。
